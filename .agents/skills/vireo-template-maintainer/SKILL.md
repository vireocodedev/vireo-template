# Vireo Template Maintainer

Specialist for Template source ownership and projection impact. The [$vireo-template router](../vireo-template/SKILL.md) selects lifecycle modes; direct use of this specialist follows the same process.

## Ordered procedure

1. **Input.** Capture the intended behavior, mode, allowed paths, profiles, consumer impact, and execution restrictions. For direct invocation, select the router's mode reference; ambiguous intent stays in plan mode. Done when the requested outcome and write boundary are explicit.
2. **Preflight.** Read and complete the [common workflow](../vireo-template/references/workflow.md), then [generated capabilities](../../../docs/generated-capabilities.md) and [project upgrades](../../../docs/project-upgrades.md). Inspect the actual source and nearest instructions; follow the common [ownership/profile preflight](../vireo-template/references/workflow.md#2-ownership-and-profiles) to locate authoritative framework projection rules for both profiles. Done when every proposed path has a rule, category, disposition, destination, and ownership consequence, or is reported blocked.
3. **Outcome.** Follow the selected mode reference. For source changes, distinguish new-project projection from existing-project adoption: identify managed updates, generated-once/application-owned work, optional selection, identity substitutions, and exclusions. Record any required framework projection/upgrade work as an owner handoff, not a Template-only workaround. Keep maintainer skills, release operations, provider evidence, and recovery instructions excluded from generated apps. Select focused source checks and both-profile clean-consumer fixtures through [verify mode](../vireo-template/references/verify.md); execution still depends on authorization. Done when the scoped change or plan accounts for all affected ownership boundaries.
4. **Stop.** Apply the common stop rules. Missing or ambiguous projection coverage blocks affected writes; customized managed bytes require an ownership decision, not overwrite flags or automatic ejection. A missing framework release or public API is an upstream dependency, not permission to enable local resolution or bump a pin. Done when each blocker has an owner and next decision.
5. **Receipt.** Return the [standard finish receipt](../vireo-template/references/workflow.md#finish-receipt), including the path/profile matrix, consumer adoption work, actual verification, and missing projection evidence. Report source changes as source changes until public and tested evidence exists.
